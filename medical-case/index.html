Medical Case Auto-Approval

An end-to-end machine learning web application that performs an initial review of medical requests and routes each case to automatic approval, automatic rejection, or doctor review based on prediction confidence.

01 / Motivation

Reduce routine review pressure without removing human oversight.

The idea came from conversations with people working in health insurance who described the pressure on doctors reviewing every request. This prototype explores whether straightforward, high-confidence cases could be accepted or rejected automatically while uncertain cases remain with a doctor.

This is a simplified proof of concept inspired by a real workflow problem. It is not deployed within an insurance company and requires further development and validation before real-world use.

02 / Solution

Confidence-based triage delivered as a web application.

The system combines a trained XGBoost classifier, reusable preprocessing artifacts, a FastAPI REST API, and a responsive Jinja2 interface. Cases with strong model confidence receive an automated outcome; lower-confidence cases are referred for human review.

04 / Model development

Trained on anonymized Saudi healthcare data.

The model used a healthcare dataset from the Saudi Open Data Platform. Development included an 80/20 train-test split, label encoding for lower-cardinality fields, target encoding for higher-cardinality fields, and XGBoost optimization with RandomizedSearchCV and five-fold cross-validation.

06 / Delivery

One project, two ways to use it.

The web interface supports interactive case submission and displays the status, predicted label, and confidence score. The FastAPI endpoint also exposes the model through a REST API for programmatic integration.

07 / Next steps

Move from proof of concept to validated workflow.

Further work should validate the system with domain experts, expand testing across representative cases, improve handling of unseen categories, evaluate confidence calibration and fairness, and add the security and governance controls required for sensitive healthcare workflows.

The application is a decision-support prototype and does not replace professional medical judgment.
