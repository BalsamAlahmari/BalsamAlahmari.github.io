Skin Disease Classification

A two-stage research prototype that uses conditional StyleGAN-generated images to increase training diversity, then classifies eight skin-disease categories with a convolutional neural network.

01 / The problem

Class imbalance limits medical-image classifiers.

Labelled dermatology images can be limited and unevenly distributed across conditions. A classifier trained on an imbalanced dataset may favor majority classes and struggle with less represented diseases.

Objective

Increase dataset diversity with class-conditioned synthetic images, then evaluate whether a CNN can learn useful distinctions across eight selected disease categories.

Scope

The work is an academic research prototype for image classification. It is not a clinical diagnostic system and was not evaluated for medical deployment.

02 / Data preparation

Eight classes prepared for a consistent pipeline.

The source Kaggle dataset contains 22 classes; the project selected eight representative categories. Images were resized to 128 × 128, normalized to [-1, 1], and augmented with rotations, flips, affine transformations, and color jitter.

03 / Technical approach

Generate, augment, classify.

01

Conditional StyleGAN

A class-conditioned generator and discriminator learn to produce synthetic examples for the selected disease classes.

02

Combined training data

Generated images are added to the real-image training set to increase class diversity and address imbalance.

03

CNN classifier

Convolution, batch normalization, pooling, dropout, and fully connected layers perform eight-class classification.

04 / Training

Separate configurations for generation and classification.

StyleGAN

  • Resolution: 128 × 128
  • Batch size: 128
  • Optimizer: Adam
  • Training configuration: 200 epochs

CNN

  • Optimizer: AdamW, learning rate 0.0005
  • Dropout: 0.3
  • Weight decay: 1e-4
  • Training: 50 epochs

05 / Results

Useful performance, with clear class-level limits.

The CNN achieved 79.11% validation accuracy. Performance was strongest for warts and acne, while visually similar categories produced more confusion.

06 / Takeaway

A practical experiment in synthetic augmentation.

The project demonstrates an end-to-end generative-and-discriminative workflow: prepare imbalanced image data, train a conditional generator, enrich the training set, and evaluate a multiclass CNN with both overall and class-level results.

This was a collaborative project.
